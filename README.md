# 命の砂時計

横スクロールのジャンプ・タイムアタックアクション。赤ちゃんで生まれ、遊ぶうちに年をとり（赤ちゃん → 少年 → 青年 → 中年 → 老人）、80 歳で寿命が尽きる。ゴールに置いてある「命の砂時計」を寿命が尽きる前にひっくり返せばクリアで、次のステージはまた赤ちゃんから始まる。5 ステージを越えると、最後の砂時計の砂が落ちきって寿命を全うするエンディング。

## 決めたこと（2026-11-03）

- 時間の表示は出さない。年齢は主人公の姿（5 段階）と、空（朝 → 昼 → 夕方 → 夜、日が昇って沈む）で伝える。道中の曲はいつもアップテンポのまま（年齢で速さを変えない。2026-11-03）。ゴールの砂時計の上の砂が、残りの寿命
- 年齢で変わるのは **歩く速さとジャンプの高さだけ**。赤ちゃんは遅く低く、青年がいちばん速く高く、老人はまた遅く低く（数値は年齢でなめらかに、絵は 5 段階で切り替える）
- 駆け引きは「青年のうちにどれだけ進めるか」。ステージは、老人になってもぎりぎり進めるように作る
- ミスは時間で払う: 敵に当たると 3 歳、穴に落ちると 2 歳、年をとる（落ちたら少し前に戻る）。体力は無い
- しかけ: 落とし穴、崩れる床、ばね、歩く敵、時限の扉、ベルトコンベア、高い段差・高い足場の近道。動く床は入れない
- 記録は「何歳でひっくり返したか」。若いほどよい
- 画面は 320 × 240、64 色（GUNZO と同じ表から）、キャラとマップは 16 × 16、砂時計は 64 × 64
- 絵は PX-13h Pixel、曲は PX-13h Music のグループ `sunadokei`（`art/GROUP.md`・`music/GROUP.md`）

## ステージの作り方（`src/stages.js`）

- 区間（平地、段、穴、ばねの壁、谷、高い足場、扉など）を並べて組み立てる
- 本道は、80 歳の体（いちばん遅く低い）でも通れるものだけで作る: 1 段の段差、1 マスの穴、ばねで上がる壁、短いコンベア、歩く敵、時限の扉（80 歳の速さでぎりぎり間に合う長さ）
- 青年でないと通れないもの（地面から 4 マス上の足場、崩れる床の橋、大きな穴を一跳び）は近道にする。落ちても遠回りになるだけ
- 調整の値は `src/main.js` の `TUNE`（一生の長さ 50 秒、速さ 0.7〜2.0、ジャンプ 28〜70 点など）

## 動かし方

```
npm install
npm run dev        # http://127.0.0.1:5194/
```

- 操作: ←→ 歩く、Z・X・Space 跳ぶ（長押しで高く）、R 赤ちゃんからやり直す、Esc タイトル。ゲームパッドも可
- スマホ（gunzo と同じ考え）: 画面の外の余白（縦持ちは下、横持ちは左右の帯。狭ければ画面に薄く重ねる）にスティックとジャンプのボタンを出す。触る所はどこでもよく、左半分がスティック（触った所から左右へずらす）、右半分がジャンプ（長押しで高く）。↺ でやり直し、✕ でタイトル。`src/main.js` の `layoutPad`
- 確かめ用の URL: `?stage=1〜5`（そのステージから）、`?age=40`（その年齢から）、`?freeze`（年をとらない）、`?life=50`（一生の秒数）、`?ending`（エンディングだけ）
- 自動の確かめ: Vite を立ててから `node tools/bot.mjs 79.9`（80 歳の体のまま 5 ステージを走らせて、通れるか）、`node tools/bot.mjs`（年をとりながら、何歳でクリアするか）、`node tools/bot.mjs shots`（各場面を撮る）。自動操作は近道を使わず、敵にもよく当たるので、人が遊ぶより遅い

## 絵・曲・文字

- 絵: `art/*.pic`（Pixel で描く）→ `node tools/art.mjs` → `src/art.js`・`src/palette.js`。仮の下書きは `node tools/draft.mjs`（無いファイルだけ書く）
- 曲: `music/*.song`（Music で作る）→ `node tools/audio.mjs` → `audio/*.ogg`・`src/bgm.js`。曲が無いあいだは無音で動く
- 文字: `art/k8x12L.bdf`（k8x12、`art/k8x12-readme.txt`）→ `node tools/font.mjs` → `src/font.js`（src/ に出てくる字だけ。`npm run dev` 中は自動）
